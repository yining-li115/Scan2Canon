# Architecture

## 范围

这一版本交付能运行的控制流程与可替换的计算边界，不实现真实重建、语义推理或移动端。先保持一个 Python 包；只有出现实际部署或依赖冲突时才拆服务。

## 依赖方向

- `domain` 仅依赖标准库和 Pydantic 数据验证。
- `ports` 声明具体工作流需要的接口，不承担调度。
- `service` 和 `harness` 依赖契约，不依赖 SQLite、HTTP 或模型 SDK。
- `storage`、`tools` 实现接口，`runtime` 组装它们。
- `cli`、`api` 是薄入口；HTTP 请求不触发长时间模型计算。
- `worker` 负责执行与本地进程互斥。策略负责提出动作，harness 检查是否允许。

当前 `BaselinePolicy` 按顺序选择未完成阶段，没有调用 LLM。策略接口是未来 VLM 的接入点，但目前只允许执行下一阶段；主动检索、追加视图和补拍需要在有实际需求时增加明确动作类型，不能绕过阶段约束。

## 工具约定

工具实现 `Tool.execute(ToolContext) -> StageResult` 并提供 `version`。在 `runtime` 中注册，不通过字符串导入任意模块，也不接受模型生成的 shell 命令。

| 阶段 | 必需产物 | 后续适配器的责任 |
| --- | --- | --- |
| inspect | capture_report | 已实现解码后的文件信息检查；清晰度、视角覆盖尚未实现 |
| reconstruct | reconstruction | 描述相机、深度或点云文件的重建清单；明确坐标和尺度约定 |
| mesh | mesh | 真实三角网格；不将点云或 3DGS 标为 mesh |
| canonicalize | pose | 满足 `CanonicalPose` 契约的 JSON |
| validate | quality_report | 独立检查几何与语义，并显式设置 quality_passed |
| export | asset | 应用变换后的可读取资产；生产适配器须验证文件内容和格式 |

产物通过 `ArtifactStore.write` 写入；工具返回引用，不把大型二进制塞入任务状态或 VLM 文本上下文。图像证据应由后续 VLM 适配器实际读取并作为图像输入，不能只提供文件名。现有 bytes 接口适合小样本；大型模型接入时再扩展流式写入和工作目录，不把几百 MB 的 mesh 反复复制进内存。

工具执行必须可重试。可恢复错误可以先由适配器处理；缺少依赖抛出 `ToolUnavailable`，需要人工判断抛出 `ReviewRequired`。未预期异常留在 worker 日志，API 只返回阶段和错误类型。

## 持久化与恢复

SQLite 的任务快照与事件在同一事务内提交。开始工具前记录尝试次数；成功后才记录已完成阶段。崩溃恢复会重跑最后一个未完成的阶段，因此执行语义是 at-least-once，不承诺 exactly-once。

本地 worker 持有同一数据目录下的 OS 文件锁；并发启动第二个 worker 会失败。进程退出后锁自动释放，新 worker 才能回收 running 任务。此机制仅支持单台机器的本地文件系统，不适用于 NFS、跨主机 GPU 池或分布式队列。未来替换为带租约、心跳和 fencing 的任务队列时，同时替换恢复策略。

导入照片时创建独立副本和 SHA-256，不依赖原目录继续存在。每次计算产物写入唯一目录，旧版本不覆盖。工具返回前未完成的写入不进入任务快照，崩溃可能留下孤立文件；当前没有自动清理程序。引入垃圾回收前需根据 manifest 和事件引用确定保留范围，不能简单按文件时间删除。

`max_attempts` 是跨重试持久保存的工具调用总预算。当前没有强制 wall-clock 超时、GPU 抢占或付费 API 额度统计；不能用 Python 同步调用承诺这些能力。接入真实 GPU 工具前，应采用可终止子进程或远程作业并增加时间和费用预算。

当前数据库 schema 为 1，pipeline version 为 1。改变流程或数据结构时显式迁移，不静默修改已有任务的解释。

## 坐标与质量

`CanonicalPose` 采用列向量：`p_canonical = R @ p_source + t`。`R` 必须正交且 determinant 为 +1。此变换只改变姿态与位置，不改变形状或推断物理尺寸。

每个姿态必须记录 `convention_id`、类别和对称性。最终 GLB 的 Y-up 约定、具体类别的语义方向及源模型轴转换由适配器显式处理。没有尺度依据时保留 `scale_known=false`。

检查旋转合法性和文件存在只能保证契约，不能保证重建正确。自动姿态预测不自动成为 ground truth，成功任务也不自动加入参考库或公开数据集。

## 接入顺序

1. 实现一个真实重建适配器，保存相机与深度/点云和完整参数，记录耗时。
2. 实现 mesh、贴图、导出与文件格式检查；保留观测缺失信息。
3. 实现 canonicalization baseline、独立质量检查与小规模评测。
4. 用同一工具接口接 VLM 决策，加入受预算限制的检查动作，比较准确率和人工成本。
5. 增加移动端上传、身份认证、用户隔离、贡献审核，再考虑远程 GPU 和对象存储。

未来基础设施的选择由实测决定。当前没有维护大规模参考库或训练任务，也不会每次扫描重新训练模型。
